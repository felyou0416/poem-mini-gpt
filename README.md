# 写诗模型项目 · 目录与工程说明

> 一个从零手写的迷你 GPT 古风写诗小模型（CPU 可训），打通全流程：**语料清洗 → 分词器实现 → 自回归 Transformer 训练 → 符号平水韵评分与 Best-of-N 重排 → 国风 Web/API 部署**。

---

## 🚀 最常用命令（在 `写诗模型` 目录下运行）

| 想做什么 | 命令 | 说明 |
|---|---|---|
| **一键写诗**（v3 全新架构） | `python scripts\poem.py 秋思` | 默认最强模型，平水韵优选，默认出 3 首 |
| 命题写诗（指定标题） | `python scripts\poem.py "《春日》"` | 自动按《标题》命题创作并生成作者与正文 |

## 📦 各模块详细介绍

### 1. 核心脚本 (`scripts/`)
| 脚本 | 作用 | 亮点与机制 |
|---|---|---|
| `rhyme_dict.py` | ⭐ **平水韵十四韵字库与格律评分器** | 华韵网《中华新韵》十四韵部整理，**7,185 个韵字**（含多音字跨韵部归并，如「行」=十唐+十一庚）；评分规则：五言字数（每句 5 字）、二四句押韵 +40 / 异韵 -40、首句入韵 +10、句内重字 -20/处、泛滥字 -10/超、不足四句 -30/句。经典《静夜思》满分 150。 |
| `poem.py` | ⭐ **一键写诗与 Best-of-N 重排序** | 底层采样 $K = \max(n\times4, 12)$ 候选发散 → `evaluate_poem` 符号打分降序优选 → 作者行附平水韵部印记（如 `〔押九文〕`）；v3 模型走特殊 token 引导（`<|bos|>`标题`<|title|>`作者`<|author|>`诗句`<|eos|>` 自动停机）。 |
| `api_server.py` | ⭐ **多模型 HTTP API 服务** | 提供 `/api/poem`、`/api/models` 与 `/health`，内存常驻多模型权重缓存，跨域支持。 |
| `train.py` | **v2 GPT 训练核心** | 4 层 MiniGPT 架构，GELU，Weight Tying，AdamW，WSD 学习率调度，断点续训保存机制。 |
| `train_v3.py` | ⭐ **v3 现代架构训练** | 6 层 / 192 维 / 6 头（每头 32 维），**RoPE 旋转位置编码 + RMSNorm**，数据自带 `<|eos|>` 停机控制，344 万参数，WSD 调度 + 断点续训。 |
| `build_bpe.py` | **BPE 子词分词器** | 从零实现 Pair 统计合并，将高频古诗词压缩 21%，支持海量文本分词与二进制打包。 |
| `build_bpe_v3.py` | ⭐ **v3 词表构建** | 严格五言清洗（每句恰好 5 字、剔除"诗题："污染行）→ 92,063 首去重 → Top 4000 高频字符（覆盖 98.7%）+ 6 特殊 token（bos/title/author/body/eos/**unk 兜底**）= 4006 词表 → 特殊 token 格式编码。 |
| `keep_training.py`| **训练看门狗守护** | 监测训练进程，若被操作系统杀死可实现 0 丢失自动重启接续（支持指定脚本，如 `train_v3.py`）。 |

### 2. 国风 Web 前端 (`前端/ui.html`)
- **设计风格**：宣纸素色（纸白/墨黑/松石黛绿）、古籍框线衬线排版、朱砂红 AI 印章徽章（“墨韵雅成”）、水墨加载动效。
- **四模型自由联动**：自动从后端 `/api/models` 接口拉取可选模型（五言BPE v3 / v2 / 五言绝句 / 通用全语料），显示参数量与语料画像。
- **平水韵韵部徽章**：解析带 `〔押X韵〕` 印记的作者行，绿色徽章高亮显示押韵部（渲染卡 / 复制 / Canvas 诗卡 / 历史记录四处联动）。
- **创作辅助**：灵感意象快捷词池（秋思、孤舟、咏梅、《春日》等）+ 双控温控滑块（附带工整/平衡/灵动/天马行空风格指导）。
- **实用诗词工具**：
  - 📋 **一键复制**：格式化诗篇拷贝（含韵部印记）；
  - 🖼️ **Canvas 宣纸海报导出**：原生 2x DPR 渲染古典图卡并自动下载 PNG；
  - 🔊 **语音慢速吟诵**：调用浏览器原生中文语音引擎带停顿朗读；
  - 📜 **会话历史留存**：可折叠抽屉查看本次生成的全部佳作。

## 🔮 v3 架构规划（✅ 全部完成 2026-09-14）

完整落地方案请参阅 [五言BPE_v3优化落地方案.md](五言BPE_v3优化落地方案.md)。
- **P0（✅）**：平水韵十四韵字库（7,185 字）与 Best-of-N 重排序接入，押韵及格率立竿见影提升（《静夜思》满分 150）；
- **P1（✅）**：Top 4,000 活跃古诗字表 + `<|unk|>` 兜底（词表 4,006）→ **6 层 / 192 维 / 6 头 RoPE + RMSNorm** 全新架构（344 万参数）→ 92,063 首严格五言预训练 6,000 步（val 3.95，对比 v2 的 6.22 大幅下降）；
- **P2（✅）**：全唐诗 30 位名家严格五言名篇 3,125 首（作者配额防风格失衡）→ LR 5e-5 / 600 步 / Dropout 0.15 / 早停 → `wuyan_bpe_v3_sft_model.pt`（val 3.39，唐风对齐）；
- **P3（✅ 并入 P1）**：特殊 token（`<|bos|>`/`<|title|>`/`<|author|>`/`<|body|>`/`<|eos|>` + `<|unk|>` 兜底）自动停机落地；SwiGLU 按验收清单暂缓（GELU MLP 已控制参数量与 CPU 时长）。
